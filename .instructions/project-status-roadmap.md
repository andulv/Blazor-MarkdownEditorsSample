# Project Status / Roadmap

## Current phase
**Prototype**

## Why
This project is a sandbox for comparing and validating markdown editor integrations in Blazor. Fast iteration, experimentation, and replacement of approaches are expected.

## Current priorities
- Evaluate behavior and ergonomics of the included markdown editors
- Improve reliability of editor initialization, synchronization, and disposal
- Keep the file-browser testing flow deterministic and local to the repository
- Document integration findings clearly enough to guide future editor selection or reuse

## Working expectations by phase
Because the project is in **Prototype** phase:
- breaking changes are acceptable
- experiments may be added, revised, or removed quickly
- verification should focus on build success and targeted manual testing of affected flows
- broader hardening and formal test coverage can be deferred until the project direction stabilizes
